Caveats

  • This is deterministic train3/test3 subset eval, not full 1000-entry cam836 eval.
  • direct_joints mode has no real MANO mesh; hand_mesh_l2_mm is unavailable and world hand videos show 21 joint points.
  • Object metrics are GT passthrough in the direct_joints eval path and are not learned object performance.
  • With n_max=1 and single-hand cam836 windows, detection is structurally easier than multi-slot DETR matching.
  • Global gamma/orientation decomposition is unavailable because this checkpoint does not predict MANO gamma/phi/theta.
