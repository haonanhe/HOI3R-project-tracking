Key discoveries

FINDING cl=16 random-stride sampling overfits the training distribution

D r5 cl=16 trained to total=0.11 then eval at non-overlapping cl=16 windows = joint L2 mean=82mm. 10× gap proves the model didn't learn the actual frame-window function — it learned the random-stride sampling artefact. THFM paper recipe (cl=81 fixed-window) is the fix; cl=81 r5 runs in flight will be the real baselines.

FIX THFM 81-frame fixed-window dataloader

_select_frame_indices_thfm: deterministic [ts, ts+1, ..., ts+T-1], pad with te when span<T. VAECacheLoader.slice_clip pads cached z_0 with last latent frame. Threaded from --encoder-mode thfm-lora. Commit 35b7330. Memprobed at cl=81 B=1 on both arm-A frame and arm-D anatomical layouts.

FIX ContextVar capture+restore across torch.utils.checkpoint recompute

set_thfm_extras_coords ContextVar leaks across use_reentrant=False recompute boundary; the patched rope_apply takes a different code path during bwd → CheckpointError 'different number of tensors saved during fwd vs recomputation'. Fix: capture _THFM_EXTRAS_COORDS.get() at fwd time, re-set inside the per-block closure. Commit a967884 (encoder_wrapper.py forward_with_queries / forward_with_extras).

FAIL save_on_cpu(pin_memory=True) overflows 208 GB ACP container at cl=81 anatomical density

OS pinned-memory limit is much smaller than container RAM. cl=81 N=64 anatomical seq=13267 tokens × 40 blocks of saved tensors crosses the budget → kernel OOM-killer (exit -9 SIGKILL). Workaround: GRAD_CKPT_OFFLOAD=0 keeps activations on GPU; fits because checkpointing means only ~one block's worth at peak. Validated on pt-jvb4y60w.

FAIL ACP marks job FAILED on post-train NCCL teardown non-zero exit

pt-sbekujs4 trained 2000 steps and saved final.pt cleanly, but ACP marked it FAILED. Cause: DDP NCCL teardown emits non-zero exit code even after dist.destroy_process_group(); bash launcher's set -euo pipefail catches it. The auto-resubmit watcher we had armed for the B=2 fallback fired spuriously and we had to DELETE the redundant submission. Future: launchers must capture PIPESTATUS[0] and treat 'non-zero exit + final.pt exists' as success.

FAIL [ test ] && cmd dies under set -e; use if/then/fi

v2ablate_*.sh GRAD_CKPT_FLAGS pattern with [ "${GRAD_CKPT_OFFLOAD:-1}" = "1" ] && GRAD_CKPT_FLAGS+=(...) — when test is false, the compound returns 1, set -e exits before mkdir -p runs, log dir doesn't exist, failure is hard to diagnose. Always if/then/fi for boolean toggles in strict-mode bash. Commit 3400b16.

FAIL scp from /tmp clobbers in-place edits made on remote

Pulled launcher to /tmp/hoi3r_edit/ early in session, sed-fixed it on remote (commit 1fe6d78), then later edited /tmp copy and scp'd back — silently reverted the on-remote sed (broke OUT_DIR override on D launcher). Caused multiple failed memprobes before diagnosis. Recovery commit 4da8752. Rule: pull-before-edit-and-push, or sed-on-remote-only — never both for the same file.
