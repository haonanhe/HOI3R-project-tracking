Key discoveries

FINDING Final-K depth threshold unchanged

K=2/4/6/8 consistently overfit on this 200-step surface, while K=16/20/24 fail. K=12 is partial/unstable: final loss drops but the last20 average stays elevated due spikes.

FAIL Hand-token RoPE worsens K=24

The appended commit 8112863 run uses the same E2 final-K K=24 settings but applies RoPE to grounded hand theta/phi/gamma tokens in each frame block. It ends with last20 6.7639, worse than the original K=24 last20 3.8823.

PASS K=8 remains in the overfit regime

K=8 reached final 0.0296 and last20 0.0324, comparable to K=2/4/6 and cross_attn_readonly.

2026-05-21 Append: Hand-Token RoPE

Using the same E2 final-K K=24 surface as the prior 219a113 run, commit 8112863 applies indexed RoPE to the grounded hand dynamic tokens theta, phi, and gamma alongside patch tokens in every VGGT frame block. This did not fix the depth failure: last20 worsened from 3.8823 to 6.7639, final loss is 6.3160, and the best transient point is 3.4557 at step 21.

Decision: hand-token RoPE in this implementation is not the missing mechanism for the K=24/all-depth failure. The stable overfit region remains K<=8, K=12 remains partial/unstable, and K>=16 still fails.
