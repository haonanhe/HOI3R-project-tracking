Key discoveries

FINDING pt_b35ydgie's period-4 obj + U-shape hand are signatures of 3-way cache misalignment

Per-frame error decomposition across 11 in-train windows reveals two distinct patterns: (a) mild U-shape on hand (f0=25.9, f01=29.8, middle ~21, f15=26.5 mm hand_vert) and (b) period-4 oscillation on obj_add_s with peaks at f04 (10.7), f08 (11.0), f15 (17.0) and troughs at f02 (4.4), f06 (5.0). Per-window analysis shows the period-4 amplitude varies systematically by sequence — driven by chunk-offset (= tracked_start mod 16): seq00 offset 9 puts window-frame-0 on chunk-floor's 7-frame lat-3 block; seq25 offset 3 on lat-1; seq49 offset 1 on lat-1. Each sequence has different latent-block-vs-PE mismatch geometry, but all consume cache at chunk-misaligned positions.

FINDING Three independent contributors at the head's PE-anchored output positions

(1) Wan2.2 4× temporal compression + asymmetric up-replication [1,4,4,7] — frames 9-15 ALL share lat 3, capping within-block discrimination. (2) Precompute chunks at sequence frame 0 (precompute_wan22_feats.py:135) but consumption (training + eval) starts at tracked_start. (3) Random training sampler picks ref_pos uniformly from [tracked_start, tracked_end] with stride 1-4 — head was trained on chaotic mixes, not stable structure. The head's additive sinusoidal PE applies rope=0 to window-frame-0 unconditionally, fighting the actual cache geometry on every consumed window.

FIX Option 2a — tracked-start-aligned cache + chunk-aligned sampler + retrain (spec written, plan ready)

Spec docs/superpowers/specs/2026-04-29-wan22-tracked-start-aligned-cache-design.md (eb79ce3) + 15-task plan docs/superpowers/plans/2026-04-29-wan22-tracked-start-aligned-cache.md (4198137). Re-precompute with --chunk-anchor tracked-start (chunks start at tracked_start, drop trailing partial); add chunk_aligned_sampling=True to _sample_frame_indices (stride=1, ref ∈ {tracked_start + 16k}); retrain from scratch on the same pt_b35ydgie 8×H100 / 50-seq sub-01-right / 15k-step envelope. No mini-eval per user 2026-04-29. Decision: hand_vert ≤ 23.60 mm AND obj period-4 amplitude ↓ ≥ 50%.

FINDING 4RC has the same precompute pattern but milder symptom — don't extend 2a to 4rc this iteration

scripts/hoi3r_v2/precompute_4rc_feats.py:98 uses identical sequence-anchored stride-16 chunking; 4rc-cached training uses the same random-ref + random-stride sampler. But 4RC has 1× compression: each input frame produces ONE distinct feature token, no within-block content sharing. Cross-chunk effect on 4rc-cached is temporal-context flavour shift (each frame's feature inherited context from its own clip's neighbors), not content jumps. Manifests as monotonic cold-start (52→25 mm hand_vert), no period-4. Recommendation: gate any 4rc-aligned retrain on the wan22-aligned outcome — if wan22 wins, 4rc-aligned is a follow-up; if wan22 loses, 4rc-aligned was unlikely to either.

Caveats

  • The alignment hypothesis is UNVERIFIED. Period-4 amplitude reduction ≥ 50% is the proof; it could fail. If it does, spec § 7 mandates pivot to 2b (THFM-LoRA, separate spec at docs/superpowers/specs/2026-04-28-hoi3r-thfm-lora-design.md).
  • 4RC retrain is intentionally NOT included in 2a. If wan22-aligned wins, 4rc-aligned is a follow-up; if it loses, 4rc-aligned is unlikely to win either.
  • chunk_aligned_sampling hard-codes stride=1 and num_views==chunk_size==16. Variable-T training (INVEST-5) needs separate spec extension if revisited.
  • Training sample diversity drops from random-ref + random-stride to ~150 unique (sequence, chunk_start) clips manifest-wide. Each clip will be presented ~12 800 times across 15k steps × global batch 128. This may overfit harder than pt_b35ydgie; canonical-point random-seed shuffle inside the head + CAD-aug provide remaining token-level diversity.
  • Trailing-partial drop: sequences whose tracked range is not a multiple of 16 lose up to 15 frames at the end. Bounded; no manifest entries are < 16 frames.
  • ACP submission requires the operator's HMAC tooling per feedback_acp_hmac_permission_scope — assistant cannot submit directly. Plan Task 13 surfaces the launcher to the operator.
  • Per memory project_cl16_d_r5_train_eval_gap.md the THFM-LoRA team independently observed the same cl=16 random-stride bug (10× train-eval gap) and shipped an 81-frame fixed-window fix at 35b7330. Our 2a is the cached-pyramid path's analogue.
