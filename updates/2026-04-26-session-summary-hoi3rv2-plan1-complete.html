Key discoveries

FIX ArcEncoderWrapper d_kv = 3072, not 1024

Encoder concats local+global at 2×HIDDEN per pyramid layer; cross-attn into encoder feats must use d_kv=3072 or first forward crashes. Also: encoder.forward requires q_hand/q_obj args (zero-fill if only feats are needed).

FIX smplx-MANO returns 16 joints, not 21

vertex_joint_selector commented out in the bundled smplx; body.joints[0].shape == (16,3). Append fingertip vertex IDs [320,443,672,555,744] in smplx-mano slot order to reach 21.

FINDING Cached encoder pyramid: trains fine, eval broken

Both runs converged to ~0.033 final loss. But the cached-run checkpoint, when re-evaluated against a live fp32 encoder forward, drops 16× (joint 67 vs 4.15 mm). Model overfit to fp16 quantization noise that doesn't survive a fresh forward. Train and eval MUST use the same feat path.

FINDING 57% end-to-end speedup from feat caching (training only)

Local 3-step single-GPU smoke: full=128.1s vs cached=55.4s. Per-step gain larger since startup is amortized. But — see eval-gap finding above — speedup is moot if eval breaks.

FIX Plan deviation: skipped Hydra/Lightning bolt-on

Wrote standalone scripts/hoi3r_v2/p1_train.py modeled on hoi3r_stage1_overfit.py. Argparse + DDP-aware. Skipped EMA. GT R/t derived per-frame via differentiable Kabsch from obj_canonical_samples → obj_posed_gt.

Caveats

  • Hand point loss is a placeholder — pred-vs-GT idx mismatch. hand_vert L2 reads 52.7 mm but joint L2 (4.15) and edge/temp_h losses carry the actual hand signal. Fix is P0 before Plan 2.
  • Cached encoder pyramid fp16 train+live-eval cross is broken (16× regression). Fix is P0 before any cached-path scale-up.
  • Effective batch differs between the two ACP runs (16 vs 8) due to p1 quota — comparison is wall-clock + final loss, not a perfectly controlled A/B.
  • Contact loss disabled in P1 (warmup-at-500 + plumbing placeholder). Doesn't affect P1 results since warmup never engages in single-seq runs at this scale.
  • smplx-MANO canonical joints differ from manopth-MANO posed joints (memory says up to 53 mm at fingertips). V2 uses smplx for canonical tokens, dataloader uses manopth for GT. P1 still hit 4.15 mm joint L2 because canonical tokens feed only into a learned MLP, but should be audited for Plan 2.
