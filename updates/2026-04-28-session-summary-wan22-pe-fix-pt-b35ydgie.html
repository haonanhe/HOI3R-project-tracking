Key discoveries

PASS Staircase artifact eliminated

pt-6pa0b3dj had 47/62 frame-pairs frozen (jump<1mm) on seq00 — predictions identical for 4-frame chunks because all chunks shared the same positional encoding. With temporal-PE (commit d7cbf65) every frame moves: 0/62 frozen pairs across all 3 sequences. Pattern: pt-6pa0b3dj first jumps were [120, 0, 0, 0, 113, 0, 0, 0, 136, 0, 0, 0, 0, 0, 0, 55] mm; pt-b35ydgie became [111, 35, 35, 33, 69, 32, 32, 34, 80, 23, 16, 25, 35, 24, 10, 80] mm. Smooth motion.

PASS Training loss improved on hand point/joint

Final-step joint MAE dropped 0.00584 → 0.00361 m (-38%), point MAE 0.00616 → 0.00399 (-35%). add_s and total slightly worse (+16% / +7%) — temporal PE shifts loss budget away from object pose without hurting it on the in-distribution metric (see cl=16 below).

PASS cl=16 eval improved (-10% hand_joint L2)

On 9 windowed cl=16 evals (matches training distribution): pt-6pa0b3dj 25.53 ± 10.78 mm → pt-b35ydgie 23.05 ± 7.12 mm. Both in-distribution mean and variance dropped.

FAIL cl=63 eval regressed dramatically

Full-sequence cl=63 mean: hand_joint 22.49 → 136.44 mm (+507%); obj_add_s 5.85 → 31.19 mm (+433%). The new RoPE temporal-PE was trained on cl=16; cl=63 frame indices are far OOD and the head loses absolute pose accuracy. Symptom matches memory project_cl_train_eval_mismatch — temporal PE makes the cl mismatch much worse, but eliminates the offending staircase. Path forward: train at intended inference clip length, or use NoPE / linear-interpolation extrapolation for inference at longer T.

FINDING Staircase root cause confirmed

The pt-6pa0b3dj head had no temporal positional encoding inside the cross-attention over per-frame pyramid tokens. The Wan2.2 pyramid groups every 4 input frames into one latent group of P=225 tokens, so the head saw the same key/value tokens repeated 4× per chunk and produced identical outputs for those 4 frames. Adding RoPE PE on the temporal axis (commit d7cbf65) breaks the symmetry and the per-frame outputs differentiate.

Headline: per-frame hand-joint jump magnitudes (the staircase)

Frame-to-frame mean L2 of the predicted 21 hand joints, in millimeters. A staircase pattern (large jumps every 4th frame, frozen between) was the symptom that motivated the temporal-PE patch (commit d7cbf65). With temporal PE, the prediction should track GT smoothly; without it the head sees identical positional encoding for all 4-frame chunks of cached pyramid features.

Definition: diff = (pred[1:] - pred[:-1]).norm(dim=-1).mean(dim=-1) * 1000 (units: mm). Three traces overlaid: pt-6pa0b3dj (no PE), pt-b35ydgie (with PE), GT.
