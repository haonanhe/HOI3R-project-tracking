Decision readout

Primary result

Delayed final-layer insertion is the only in-backbone hand-token strategy here that overfits reliably. K=2, K=4, and K=6 all reach last20 around 0.039-0.040, while all-depth insertion and layer0_oneway remain flat around 3.8-4.0 despite nonzero LoRA and hand gradients.

Interpretation

The failure is not simple gradient starvation. Both negative in-backbone runs have LoRA and hand gradients on all 200 steps. The current evidence points to early hand-token insertion disrupting the loaded VGGT representation; masking native tokens from reading hand-token K/V at every layer is not sufficient to recover overfit.

Caveat

The comparison intentionally keeps the same earlier control surface. Current max_manifest_size=1 is still not a strict fixed-window gate, so this is a consistent one-manifest overfit comparison rather than a strict single-window proof.
