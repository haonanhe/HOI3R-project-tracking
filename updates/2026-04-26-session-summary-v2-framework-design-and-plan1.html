Key discoveries

FINDING Math doc and V1 evidence converge on hand+object asymmetry

Hand has shared canonical manifold across MANO topology; object has no shared dense point identity across mug/banana/scissors. V1's predict-points-then-Procrustes hides train regression. Right answer per math doc: hand = NLF canonical-trajectory, object = shape-conditioned SE(3) trajectory. This is the core architectural delta in v2.

FINDING β++ multi-layer cross-attn resolves the frozen-vs-LoRA dilemma

Pure-frozen starves queries (validated by pt-ivn0p7l0 > pt-6ttdqgom on 2026-04-26). Pure LoRA pollutes patch tokens. β++ exposes 4 encoder layers (out_layers=[19,27,33,39], already wired per reference_arc_encoder_wrapper_feats) to query decoders via one-way cross-attn — frozen weights, multi-depth access, no pollution risk. LoRA stays as ablation row 7.

FINDING 4-phase curriculum (P1→P4) maps cleanly to paper claim ladder

P1 single-seq (validates architecture; reproduces V1 12.35/9.2 anchor); P2 within-subject (closes historical multi-seq regression); P3 DexYCB s1 (the (iii) primary cross-subject result); P4 multi-dataset (DexYCB ∪ HO3D ∪ H2O3D ∪ H2O ∪ HOT3D, requires bimanual unlock). Each phase has a calibrated metric gate to the next.

FINDING (iv) cross-object zero-shot is supported via SAM-3D-Objects + scale prior

At test, SAM-3D-Objects produces a mesh from a single best-frame; PCA-aligned + scale-rectified to a per-category prior; pose decoder treats it as another CAD source. Per-category scale prior is a documented limitation (truly scale-free needs monocular metric depth). Plan-B fallback: TripoSR / TRELLIS / InstantMesh.

FIX feedback_frozen_vs_lora_contested supersedes simple framing

Earlier project_motion_grounding_ablation_results read as 'frozen wins' on a 4-cell ablation. Newer bundled-vs-frozen-3-lever (pt-ivn0p7l0 vs pt-6ttdqgom) shows bundled-LoRA-stack wins on subject-01 single-seq overfit. Don't quote the earlier finding as decisive.
